# Attack-on-Titan-Elimination-Simulator
This project is inspired by Attack on Titan (one of my favorite animated series) that calculates how many Titans a Survey Corps scout can eliminate. It is a very basic JavaScript(Node.js) program that reads values from standard input, finds the smallest value, and prints the result. This project was done in one of my classes so if you have any suggestions/comments, pls feel free to reach out :).
